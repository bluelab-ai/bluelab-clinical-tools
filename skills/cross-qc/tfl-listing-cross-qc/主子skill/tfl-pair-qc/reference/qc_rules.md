# 临床试验 Table vs Listing 反向核查规则

## 总体质控规则

核心原则：**Table 里的每一个人数、例次数、百分比，原则上都应能从 Listing 中算出来。**

### 1. 人数去重
Table 人数应等于 Listing 中受试者去重人数。例：Table 显示腹泻 11 人，但 AE Listing 按受试者去重只有 10 人 → 提示差异。

### 2. 例次数 vs 人数
人数和例次数要区分。一个受试者可以有多条 AE 记录，AE 例次数可以大于人数。例次数 = Listing 中对应记录数（不去重）。

### 3. 组别一致性
Listing 按试验组/对照组聚合后，应与 Table 各组人数一致。

### 4. 时间窗一致性
如术后 30 天、6 个月、12 个月事件，应根据手术/给药日期和事件发生日期判断，不能把超窗事件计入。（暂缓）

### 5. 分析集一致性
Table 写 FAS，就只能用 FAS Listing 反推；Table 写 SS，就只能用 SS Listing 反推。

### 6. 衍生指标可追溯
量表总分、分项分、复合终点、降解百分比、骨折愈合率等，Listing 中应能看到原始值、衍生结果或判断依据。

## 不良事件、严重不良事件类（AE/SAE）

### 1. AE Table 和 AE Listing 一致
基础核对。

### 2. SAE 必须在 AE Listing 中找到
每条 SAE 应同时出现在 AE Listing 中，并标记为严重不良事件。

### 3. 死亡链路一致
死亡人数应与死亡清单、AE 转归为死亡、SAE 转归为死亡、受试者退出原因相互一致。

### 4. 因 AE/SAE 退出必须有 AE/SAE 记录
如果 Table 显示因 AE 退出的人很多，但 AE Listing 中发生 AE 的人很少；或某个因 AE 退出的受试者没有 AE 记录 → 重大逻辑问题。

### 5. AE 处理用药和合并用药对应（暂缓）

## 事件类指标（疗效/安全性双重身份）

### 1. 同一事件在疗效表和安全性表中互相解释
如疗效表卒中 5 人，但安全性 AE 表只有 1 人 → 应检查分析集、时间窗、事件定义是否不同。无解释则提示差异。

### 2. 时间窗计数（暂缓）

### 3. 复合终点和组成事件一致
复合终点为"是" → 至少一个组成事件为"是"。组成事件发生 → 复合终点通常也应计入（除非 SAP 另有定义）。

## 实验室、生命体征、体格检查

### 1. 异常 Listing 和交叉表一致
Listing 中有临床意义异常，但 Table 显示均正常 → 提示差异。

### 2. 访视间转归符合交叉表
正常→异常、异常→正常、异常→异常等分类，应能从 Listing 反推。

### 3. 连续变量统计量常识检查
最小值 ≤ Q1 ≤ 中位数 ≤ Q3 ≤ 最大值；均值在最小值和最大值之间。

### 4. 缺失值处理
n + 缺失数应等于对应分析集分母。

### 5. 文本值不能参与连续变量计算
如体重为"未做"，不能进入均值、标准差计算。

## 不在此规则范围内的项目（禁止添加）

- 统计方法选择是否恰当（如卡方 vs Fisher）
- 表格格式/排版/字体问题
- 表格编号/标题是否规范
- 数据本身的临床合理性判断
- 非 Listing 可反推的指标（如研究者主观判断）

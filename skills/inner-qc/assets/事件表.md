# 事件表 · QC 核查规则与代码

**对应类型**：`事件表`（CSV 文件名里的"类型"字段）
本文档两部分：**一、自然语言规则** ｜ **二、代码模板**。

---

## 这类表是什么

不良事件（AE）类统计表，双行表头。一般每个事件一行，每组用"例次 / 人数(百分比)"记录，如某事件试验组 `3(6.0%)` ——表示 3 人发生、占该组 6%。

---

# 一、自然语言规则

## 本表内即可完成的规则

### R-015　百分比 = 人数 ÷ 组总人数
- **查什么**：每个"人数(百分比)"格子，百分比应等于"该格人数 ÷ 这一组总人数 × 100"。
- **怎么算**：如试验组共 50 人，某事件 3 人，应为 3 ÷ 50 = 6.0%。
- **判定**：差 ≤ 0.15 个百分点→通过；差太多→问题；组总人数取不到→跳过。

## 需要"人群划分表"数据作基准的规则

> 用到人群划分表给出的各组人数。有基准文件就核对，否则留合并阶段。

### R-009　表头各组 N ↔ 人群划分表
- 表头每组总人数，不应超过人群划分表里该组（SS）的人数。

### R-028 / R-036　标签一致性
- R-028：表题分析集与本表合计人数上限（合计 > `baseline[表题集]["合计"]` 才报 MAJOR；相等或子集都不报）。
- R-036：表头若出现 FAS/ITT/mITT/PPS/SS 字样，要与表题声明一致。

## 2.2 本表规则核查片段

```python
# level 取 CRITICAL/MAJOR/MINOR/SUGGESTION/待人工；数据算术违例默认 MAJOR。

# R-015 百分比=人数/组N（已定位到事件 event、组 group、单元格 cell、组总人数 N）
n, p = parse_n_pct(cell)                     # "3(6.0%)"
if n is not None and N:
    if check_pct(p, n, N) is False:
        iss.add("R-015", "MAJOR", f"{event}·{group}", round(n / N * 100, 1), p)
```

## 2.3 需要基准的规则片段（baseline 从人群划分表读入）

```python
# baseline={"SS":{"试验组":50,"对照组":49,"合计":99},...}；ts=表题分析集；nbg={组:N}；name=表名

# R-009 表头各组N ≤ 人群划分表
for g, n in nbg.items():
    if ts in baseline and g in baseline[ts] and check_le(n, baseline[ts][g]) is False:
        iss.add("R-009", "MAJOR", f"{g}·{ts}", f"≤{baseline[ts][g]}", n)

# R-028 表题分析集 ↔ 本表合计（合计 > baseline 才报，允许子集表）
if ts in baseline and nbg.get("合计") is not None and nbg["合计"] > baseline[ts]["合计"]:
    other = [S for S in baseline if baseline[S]["合计"] == nbg["合计"] and S != ts]
    hint = f"（另与 {'/'.join(other)} 合计相同）" if other else ""
    iss.add("R-028", "MAJOR", f"表题{ts}", f"≤{baseline[ts]['合计']}", f"{nbg['合计']}{hint}")

# R-036 表头出现的 FAS/ITT/mITT/PPS/SS ⊆ 表题集合
bad = {g for g in nbg if g in ("FAS", "ITT", "mITT", "PPS", "SS")} - set(title_set_list)
if bad:
    iss.add("R-036", "MAJOR", "表题↔表头", f"⊆{title_set_list}", "、".join(sorted(bad)))
```

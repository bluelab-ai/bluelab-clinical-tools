# 协方差 / 修正均数表 · QC 核查规则与代码

**对应类型**：`协方差`（CSV 文件名里的"类型"字段）
本文档两部分：**一、自然语言规则** ｜ **二、代码模板**。

---

## 这类表是什么

协方差分析(ANCOVA)、修正均数(最小二乘均数 LSMean)、组间差值及置信区间、P 值等。这些数字由 SAS 等统计软件**直接计算输出**，涉及模型拟合，无法用简单四则运算复核。

---

# 一、自然语言规则

## 核查原则：跳过数值重算

- **不要**手工重算修正均数、置信区间、P 值——依赖统计模型，重算无意义且会误报。
- 数值部分一律标"不核查（SAS 直出）"。

## 仅做的检查

### 置信区间方向（可选，若表里给出）
- 置信区间下限 ≤ 点估计 ≤ 上限。明显颠倒→问题。

> 这类表的真正价值在跨文件结论一致性（主要终点是否与正文/SAP 吻合），属合并阶段或人工复核，不在单表 QC 范围。

---

# 二、代码模板

> 本类几乎不做数值核查，模板很短：标注跳过 + 表题标签检查 + 可选的置信区间方向。

# 数值部分：标注不核查（SAS 直出）
iss.add("协方差", "待人工", "全表", "—", "—",
        "SAS 直出，数值不做四则复核；如需核对主要终点请走合并阶段")

# 置信区间方向（已定位到 下限 lo、点估计 est、上限 hi 时）
if check_ordered([lo, est, hi]) is False:

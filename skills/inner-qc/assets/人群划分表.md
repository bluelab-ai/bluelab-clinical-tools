# 人群划分表 · QC 核查规则与代码

**对应类型**：`人群划分表`（CSV 文件名里的"类型"字段）
本文档两部分：**一、自然语言规则** ｜ **二、代码模板**。

---

## 这类表是什么

分析集划分表。给出每个分析集（FAS 全分析集 / PPS 符合方案集 / SS 安全集）在各组（试验组/对照组/合计）的人数。**这张表是其他所有表的"人数基准来源"**——QC 时它本身要先自洽。

---

# 一、自然语言规则

## 本表内即可完成的规则

### 各分析集内：合计 = 各组之和
- **查什么**：每个分析集若有"合计"列，合计人数应等于各组人数相加。
- **判定**：相等→通过；对不上→问题。

### R-020　分析集人数边界
- **查什么**：分析集之间的包含关系——
  - 符合方案集(PPS) ≤ 全分析集(FAS)（PPS 是 FAS 里依从性好的子集）；
  - 全分析集(FAS) ≤ 随机总人数；
  - 安全集(SS) ≤ 随机总人数。
- **判定**：满足"≤"→通过；某子集反而更大→问题。
- **提示**：随机总人数若本表没有，可取自随机表或病例分布表入组合计（合并阶段提供）。

## 需要外部文件的规则（如已提供）

### R-031　与随机表 / 人群划分决议一致
- 若提供了外部随机表或人群划分决议：本表各分析集各组人数应与之**完全一致**（精确相等）。
- 没有外部文件→跳过。

### R-051　分析集人数与 external_ref 一致（FAS/ITT/mITT/PPS/SS）
- 若 Phase 3 已产出 `external_ref.json`：本表各分析集的试验组/对照组/合计人数应等于 `external_ref.by_analysis_set[集]`。
- 与 R-031 的区别：R-031 面向外部"随机表/决议"（受试者级），R-051 面向合并后的 `external_ref`（已聚合）；两者数据源相同但接口不同，可并存也可只留 R-051。

### R-050　各中心的试验组/对照组/合计病例数一致（若本表有分中心维度）
- 部分人群划分表除了分析集维度还按中心分小组；此时各中心各组人数应等于 `external_ref.by_center[中心号]`。
- 无分中心维度→跳过。

### R-053　剔除原因文本对应
- 本表若列有"剔除原因/脱落原因"列（每受试者一行的形式），聚合后各原因计数应等于 `external_ref.exclusion_reasons`。
- 若外部无对应文本→标 MINOR（措辞差异需人工核对）。

> **本表抽出的 `FAS/PPS/SS × 各组人数`，要存成基准文件**，供其他表的 R-003/009/028/036 使用。

# 二、代码模板

> subagent 读入 xlsx 后，把表解析成 `pop = {"FAS":{"试验组":50,"对照组":48,"合计":98}, "PPS":{...}, "SS":{...}}`，再核查。工具函数从共享库 `qc_lib` import。**核查完别忘了把 `pop` 写出为 `tables_output/baseline.json`（波次0 的核心产物）。**

## 2.1 通用工具 + 骨架（复制即用）

```python
import sys, os, json
sys.path.insert(0, "scripts")   # ← 换成本 skill 的 scripts 目录（绝对路径更稳）
from qc_lib import read_grid, to_num, check_sum, check_le, check_equal, lead_int, Issues

# 由 dispatch 提示给出：XLSX_PATH、IDX(编号)、TITLE(表题)
grid = read_grid(XLSX_PATH)                     # 读 xlsx，二维 str（替代旧 pd.read_csv）
iss  = Issues(table_index=IDX, table_type="人群划分表", title=TITLE)
# pop = 解析 grid 得到的 {分析集:{组:人数}}（按本表实际布局定位）

# —— §2.2 用到的可选输入，默认为 None（表内取不到就跳过对应规则）——
rand = None    # 随机总人数，可由合并阶段/病例分布表传入；无则 R-020 的 FAS/SS ≤ 随机 分支跳过
ref  = None    # 外部随机表 / 人群划分决议 {分析集:{组:人数}}；无则 R-031 跳过

# 加载 external_ref（可选；文件不存在则 R-050/R-051/R-053 静默跳过）
ext_ref = {}
_ref_path = "tables_output/external_ref.json"
if os.path.exists(_ref_path):
    with open(_ref_path, encoding="utf-8") as f:
        ext_ref = json.load(f)

# 核查完毕后落盘：iss.to_json(f"qc_output/qc_{IDX}.json")
```

## 2.2 本表规则核查片段

```python
# level 取 CRITICAL/MAJOR/MINOR/SUGGESTION/待人工；本表是基准源，违例默认 MAJOR。

# 各分析集：合计 = 各组之和
for S in ("FAS", "PPS", "SS"):
    grp = pop.get(S, {})
    if "合计" in grp:
        parts = [v for g, v in grp.items() if g != "合计"]
        if check_sum(grp["合计"], parts) is False:
            iss.add("合计一致性", "MAJOR", f"{S}·合计", sum(to_num(x) for x in parts), grp["合计"])

# R-020 分析集人数边界（rand=随机总人数，可由合并阶段传入）
if check_le(pop["PPS"]["合计"], pop["FAS"]["合计"]) is False:
    iss.add("R-020", "MAJOR", "PPS≤FAS", f"≤{pop['FAS']['合计']}", pop["PPS"]["合计"])
if rand and check_le(pop["FAS"]["合计"], rand) is False:
    iss.add("R-020", "MAJOR", "FAS≤随机", f"≤{rand}", pop["FAS"]["合计"])
if rand and check_le(pop["SS"]["合计"], rand) is False:
    iss.add("R-020", "MAJOR", "SS≤随机", f"≤{rand}", pop["SS"]["合计"])

# R-031 与外部随机表/决议一致（ref=外部数据，没有则跳过；精确相等，错配可判 CRITICAL）
if ref:
    for S in ("FAS", "PPS", "SS"):
        for g, v in ref.get(S, {}).items():
            if check_equal([pop.get(S, {}).get(g), v]) is False:
                iss.add("R-031", "MAJOR", f"{S}·{g}", v, pop.get(S, {}).get(g))
```

## 2.4 用 external_ref 的规则片段（**Phase 3 专用**）

> **执行阶段**：Phase 3 外部核查阶段执行；Phase 4/5 subagent 请**跳过本节**（Phase 3 已产出对应报告 `qc_ext_<编号>.json/md`）。
> Phase 3 subagent 只跑本节的 R-050~R-053；不跑 §2.2 / §2.3。

```python
# R-051 分析集人数与 external_ref 一致
by_set = ext_ref.get("by_analysis_set") or {}
for S, ref_groups in by_set.items():
    tbl_groups = pop.get(S, {})
    if not tbl_groups:
        continue
    for grp, expected in ref_groups.items():
        actual = tbl_groups.get(grp)
        if actual is None:
            continue
        if check_equal([actual, expected]) is False:
            iss.add("R-051", "MAJOR", f"{S}·{grp}", expected, actual)

# R-050 分中心一致性（若本表有分中心维度：center_rows=[(cid, {"试验组":n,"对照组":n,"合计":n}),...]）
# by_center 新结构：{"01": {"FAS":{"试验组":..,"对照组":..,"合计":..}, "PPS":{...}, ...}, "合计":{...}}
# 只计"纳入"。人群划分表通常按分析集切片：subagent 应对本表出现的每个分析集
# 循环 R-050，而不是只对一个 analysis_set。
by_center = ext_ref.get("by_center") or {}
# center_rows 可扩展为按分析集索引：center_rows_by_set = {"FAS": [(cid, groups),...], "PPS":[...], ...}
if by_center and center_rows_by_set:
    for a_set, rows_ in center_rows_by_set.items():
        if a_set not in ("FAS", "PPS", "SS", "ITT", "mITT"):
            continue
        for cid, groups in rows_:
            # 中心号可能带前导零（"01" vs "1"），两边尝试
            center_data = by_center.get(str(cid)) or by_center.get(str(cid).lstrip("0") or "0")
            if not center_data:
                continue
            ref_row = center_data.get(a_set)
            if not ref_row:
                continue
            for grp in ("试验组", "对照组", "合计"):
                actual = groups.get(grp)
                expected = ref_row.get(grp)
                if actual is None or expected is None:
                    continue
                if check_equal([actual, expected]) is False:
                    iss.add("R-050", "MAJOR", f"中心{cid}·{a_set}·{grp}", expected, actual)

# R-053 剔除原因文本对应（若本表列有剔除原因：reason_rows=[(text, count_cell),...]）
ext_reasons = ext_ref.get("exclusion_reasons") or {}
if ext_reasons and reason_rows:
    for reason, cell in reason_rows:
        actual = lead_int(cell)
        expected = ext_reasons.get(reason)
        if actual is None:
            continue
        if expected is None:
            iss.add("R-053", "MINOR", f"剔除原因·{reason}", "外部有该文本", "未匹配（措辞差异？）")
        elif check_equal([actual, expected]) is False:
            iss.add("R-053", "MAJOR", f"剔除原因·{reason}", expected, actual)
```

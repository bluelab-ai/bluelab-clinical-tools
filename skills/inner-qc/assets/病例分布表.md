# 病例分布表 · QC 核查规则与代码

**对应类型**：`病例分布表`（CSV 文件名里的"类型"字段）
本文档两部分：**一、自然语言规则** ｜ **二、代码模板**。

---

## 这类表是什么

受试者流向表。每组（及合计）一行，列出入组人数、完成人数、脱落人数（有时还有筛选、剔除等）。

---

# 一、自然语言规则

### R-010　入组 = 完成 + 脱落
- **查什么**：每一行（每组及合计），入组人数应等于完成人数加脱落人数。
- **怎么算**：如试验组入组 50、完成 47、脱落 3 → 47+3=50 ✅；入组 50、完成 42、脱落 7 → 49≠50 ❌。
- **判定**：相等→通过；对不上→问题（人数守恒，应精确相等，不允许零头）。
- **提示**：数字若带括号或百分号（如"47(94%)"），只取前面的人数来算。

## 需要"外部参照"的规则（`external_ref.json` 存在时执行）

> 由 Phase 3 `prepare_external_ref.py` 从人群划分表/随机表抽出的 `by_center` /
> `exclusion_reasons` 作基准；若外部参照未涵盖某项，本条静默跳过（不报"通过"）。

### R-050　各中心的试验组/对照组/合计病例数一致性
- **查什么**：本表若有"分中心"维度（每中心一行/列），各中心的试验组/对照组/合计人数应等于 `external_ref.by_center[中心号]`。
- **判定**：数字完全一致→通过；不一致→MAJOR；外部无该中心记录→跳过。
- **对齐**：本表中心号可能是"01/中心 01/合肥高新..."，与 external_ref 键（如"01"）匹配前要做前导零/别名归一。

### R-053　剔除原因/脱落原因对应
- **查什么**：本表若列出"剔除原因/脱落原因"及计数，各原因文本应能在 `external_ref.exclusion_reasons` 里找到；总数应一致。
- **判定**：原因文本命中且计数吻合→通过；原因文本外部无对应但本表有 → MINOR（可能措辞差异，需人工）；计数明显偏离→MAJOR。

# 二、代码模板

> subagent 读入 xlsx 后，定位每行（组别）的入组/完成/脱落单元格，取前导整数后核查。所有工具函数从共享库 `qc_lib` import。

## 2.1 通用工具 + 骨架（复制即用）

```python
import sys, os, json
sys.path.insert(0, "scripts")   # ← 换成本 skill 的 scripts 目录（绝对路径更稳）
from qc_lib import read_grid, to_num, lead_int, check_sum, check_equal, Issues

# 由 dispatch 提示给出：XLSX_PATH、IDX(编号)、TITLE(表题)
grid = read_grid(XLSX_PATH)                     # 读 xlsx，二维 str
iss  = Issues(table_index=IDX, table_type="病例分布表", title=TITLE)

# 加载外部参照（可选；文件不存在则 R-050/R-053 静默跳过）
ext_ref = {}
_ref_path = "tables_output/external_ref.json"
if os.path.exists(_ref_path):
    with open(_ref_path, encoding="utf-8") as f:
        ext_ref = json.load(f)

# 核查完毕后落盘：iss.to_json(f"qc_output/qc_{IDX}.json")
```

## 2.2 本表规则核查片段

```python
# level 取 CRITICAL/MAJOR/MINOR/SUGGESTION/待人工；人数守恒违例默认 MAJOR。

# R-010 入组=完成+脱落（已定位到每行 label、入组/完成/脱落单元格）
enr  = lead_int(cell_入组)
comp = lead_int(cell_完成)
drop = lead_int(cell_脱落)
if None not in (enr, comp, drop):
    if check_sum(enr, [comp, drop]) is False:
        iss.add("R-010", "MAJOR", f"{label}·入组", comp + drop, enr)
```

## 2.3 用外部参照的规则片段（**Phase 3 专用**）

> **执行阶段**：Phase 3 外部核查阶段执行；Phase 5 subagent 请**跳过本节**（Phase 3 已产出对应报告 `qc_ext_<编号>.json/md`）。
> Phase 3 subagent 只跑本节的 R-050 / R-053；不跑 §2.2 的 R-010。

```python
# R-050 分中心的试验组/对照组/合计一致（已定位到每中心行、组别列的单元格）
# by_center 结构：{"01": {"随机化人群":{...}, "FAS":{...}, "PPS":{...}, ...}, "合计":{...}}
# 病例分布表分析集通常是"随机化人群"——查同名槽位（中心内每筛选号一人）；
# 若表明确落到 FAS/PPS/SS/ITT/mITT，查对应槽（只算被标"纳入"）。为 "-" 才跳过。
_ACCEPT = ("随机化人群", "FAS", "PPS", "SS", "ITT", "mITT")
by_center = ext_ref.get("by_center") or {}
analysis_set = "<从 ##META_ANALYSIS_SET 取，如 '随机化人群'>"  # subagent 应从元数据填入
if by_center and center_rows and analysis_set in _ACCEPT:
    for cid, cells in center_rows:       # center_rows: [(cid, {"试验组":cell,"对照组":cell,"合计":cell}),...]
        center_data = by_center.get(str(cid).lstrip("0") or "0") or by_center.get(str(cid))
        if not center_data:
            continue                     # 外部无此中心 → 跳过
        ref_row = center_data.get(analysis_set)
        if not ref_row:
            continue                     # 外部此中心该分析集无人 → 跳过
        for grp in ("试验组", "对照组", "合计"):
            actual = lead_int(cells.get(grp))
            expected = ref_row.get(grp)
            if actual is None or expected is None:
                continue
            if check_equal([actual, expected]) is False:
                iss.add("R-050", "MAJOR", f"中心{cid}·{analysis_set}·{grp}", expected, actual)

# R-053 剔除原因/脱落原因对应（已定位到每原因行 reason_rows: [(reason_text, count_cell), ...]）
ext_reasons = ext_ref.get("exclusion_reasons") or {}
if ext_reasons and reason_rows:
    for reason, cell in reason_rows:
        actual = lead_int(cell)
        expected = ext_reasons.get(reason)
        if actual is None:
            continue
        if expected is None:
            iss.add("R-053", "MINOR", f"剔除原因·{reason}", "外部有对应文本", "未匹配（措辞差异？）")
        elif check_equal([actual, expected]) is False:
            iss.add("R-053", "MAJOR", f"剔除原因·{reason}", expected, actual)
```

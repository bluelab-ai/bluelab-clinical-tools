动画体系 — Fluid Storytelling

有节奏的入场、方向性的过渡、弹性缓动。以下为全局可复用的动画定义

缓动曲线

ease-out

入场动画
cubic-bezier(0.16, 1, 0.3, 1)

ease-spring

弹性反馈
cubic-bezier(0.34, 1.56, 0.64, 1)

ease-in-out

状态切换
cubic-bezier(0.65, 0, 0.35, 1) — 默认

入场动画 — 按方向叙事

fade-in-up 透明度 0→1 + translateY(12px→0) 消息入场
fade-in-right 透明度 0→1 + translateX(16px→0) 面板滑入
scale-in 透明度 0→1 + scale(0.95→1) 弹窗/菜单
slide-down translateY(-8px→0) + 透明度 下拉/展开

微交互 — 操作反馈

按钮 hover

scale(1.02) + 阴影扩散

duration: 200ms, ease-spring

卡片 hover

translateY(-2px) + 边框增亮

duration: 200ms, ease-out

输入框聚焦

边框发光 + 微缩放

box-shadow glow ring

Stagger 延时 — 列表叙事感

列表项/消息按 60ms 间隔依次入场，营造「流畅叙事」节奏

delay: 0ms → 60ms → 120ms → 180ms → 240ms

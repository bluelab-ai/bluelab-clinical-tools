各组件改造要点

ChatPage 顶部栏升级：半透明毛玻璃 + 底部微光边框。状态条改为深色胶囊标签。整体背景 #09090b
ChatMessage 消息气泡微调：角色标签改为细线胶囊。代码块深色底+紫色关键词高亮。blockquote 边框改为紫色渐变
FileSidebar 深色底 #121216 + 微光右边界。文件项 hover 时背景渐变 + 左移 2px。分类标签改为细线分隔
ChatInput Generate DMP 按钮升级：紫色渐变底 + hover 发光扩散。disabled 态改为半透明
QuestionCard 选项按钮改深色底 + 亮边框，选中态紫色渐变边框 + 微弱发光。输入框聚焦环改用紫色光晕
ReportPanel 独立深色面板 + 左侧紫色竖线标识。拖拽手柄 hover 时紫色发光。内容区自定义滚动条改为紫色调
Login / Register 卡片升级深色底 + 微光边框。输入框深色填充 + 聚焦紫色光晕。按钮紫色渐变。背景加微妙的网格纹理
LogForm / Help 统一深色主题背景 + 卡片式表单区域。帮助页步骤卡片增加 stagger 入场动画

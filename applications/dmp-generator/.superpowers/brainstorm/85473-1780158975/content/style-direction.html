你更偏好哪种「高级感」设计风格？

选择一种最接近你心中理想的方向，这会影响后续的配色、间距、组件样式等所有设计决策

A

极简留白 — Minimalist

大量留白、纤细线条、克制用色（类似 Linear / Stripe / Apple 风格）。以空间和排版本身传达品质感，少即是多。

B

精致玻璃 — Glassmorphism

毛玻璃效果、柔和渐变背景、半透明卡片、弥散阴影（类似 macOS / iOS 现代风格）。层次感强，光影丰富。

C

深色奢华 — Dark Premium

深色底为主、细腻的灰色阶、微妙的渐变光晕、精致的边框高光（类似 Vercel / GitHub 暗色模式）。沉稳而现代。

D

柔和暖调 — Warm Elegance

米白/奶油底色、暖灰调、微妙的琥珀/金点缀、柔和阴影（类似 Notion / Linear 亮色模式）。温暖而有质感。

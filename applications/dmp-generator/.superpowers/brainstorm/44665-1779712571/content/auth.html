User Auth & Workspace Isolation

JWT认证 + SQLite用户表 + 文件系统隔离

数据模型

-- SQLite: users 表
CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL, -- bcrypt hash
  workspace TEXT UNIQUE NOT NULL, -- "user_alice"
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 注册时自动生成 workspace = "user_" + username
-- 同步在文件系统创建 data/workspaces/{workspace}/

认证流程

注册 POST /api/auth/register
  • 校验 username 唯一性
  • bcrypt 加密密码
  • 写入 users 表
  • 创建 data/workspaces/{username}/
  • 返回 JWT token（含 user_id + workspace）
登录 POST /api/auth/login
  • 查询 users 表
  • bcrypt 校验密码
  • 返回 JWT token
  • 前端存入 localStorage

# 路径安全: 校验所有文件路径是否在用户workspace内
def safe_path(workspace, filename) → Path:
    p = BASE / workspace / filename
    assert p.resolve().is_relative_to(BASE / workspace)
    return p
安全要点： 所有文件IO都经过 safe_path 校验，防止路径穿越攻击（如 ../../etc/passwd）

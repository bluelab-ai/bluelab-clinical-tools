API 设计

POST /api/files/upload
  → multipart/form-data, file字段
  → 保存到 data/workspaces/{workspace}/
  → 校验扩展名白名单: .docx .pdf .txt .md
  → 校验文件大小上限: 50MB
  → 同名文件自动覆盖，旧文件加 .bak 后缀
  → 返回 {filename, size, uploaded_at}

GET /api/files/list
  → 扫描用户工作目录
  → 返回文件列表 [{name, size, type, modified_at}]
  → 按类型分类: 方案文档 / 日志文件 / DMP输出

GET /api/files/download/{filename}
  → 下载工作目录中的文件
  → Content-Disposition: attachment

DELETE /api/files/delete/{filename}
  → 删除指定文件（仅限方案文档，日志和DMP不允许删除）

上传后的流程衔接

1 用户上传方案文档 → 2 文件保存到工作目录 → 3 侧边栏文件列表更新 → 4 可在聊天中引用文件开始DMP生成

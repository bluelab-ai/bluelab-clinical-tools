Error Handling & Edge Cases

覆盖关键异常场景与防御设计

关键异常场景

场景 处理策略
Claude SDK 调用失败/超时 SSE 推送 error 事件，提示用户重试；保留当前 session 上下文，重试不从头开始
DMP 生成中用户关闭页面 后端 session 保留 N 分钟，用户重新打开可恢复；超时后 session 销毁，下次从起点开始
工作目录中缺少必要文件（无日志/无方案） DMP 生成按钮 disabled，聊天框提示：请先完成日志填写和方案上传
方案文档解析失败（加密PDF/损坏docx） Claude 读取文件时报错 → SSE error 事件 → 提示用户检查文件格式
磁盘空间不足 文件写入失败 → SSE error 事件 → 提示管理员清理空间
并发生成（同一用户重复点击） 后端检查是否已有进行中的 session，有则拒绝新请求，"已有生成任务进行中"
JWT 过期 前端拦截 401，弹出重新登录提示；token 有效期 24h
多用户同时生成 每个用户独立 session + 独立工作目录，天然隔离，无需额外处理

安全防线清单

密码

bcrypt 哈希存储，前端也做最小长度校验(≥6位)

路径

所有文件操作经 safe_path 校验，限制在用户工作目录内

上传

扩展名白名单 + 文件大小上限 + 文件类型魔数校验

SQL注入

使用 ORM(SQLAlchemy) 参数化查询，不拼接 SQL

CORS

仅允许前端域名跨域访问，生产环境不开放 *

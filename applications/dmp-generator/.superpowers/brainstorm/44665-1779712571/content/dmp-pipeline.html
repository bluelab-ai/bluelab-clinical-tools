关键技术点

Tool Use 白名单

Claude SDK 的 tool_use 限定为 Bash(只允许运行指定脚本) + Read(只允许读工作目录)，保证安全不越权

Session 管理

每个用户一个 Claude SDK session，保存在后端内存，session 存活期间保持上下文，超时或用户主动重置时销毁

过程可见性

所有 tool_use 执行状态通过 SSE 实时推送，用户在聊天框中看到 Claude 正在执行哪个脚本、结果如何

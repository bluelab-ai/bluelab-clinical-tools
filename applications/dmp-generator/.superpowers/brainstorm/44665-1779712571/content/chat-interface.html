SSE 事件类型设计

event: text ← Claude流式输出文本
event: question ← Claude需要用户输入
data: {questions:[{id,text,type:"choice"|"input",options?}]}
event: tool_use ← Claude调用脚本(如build_dmp_trace)
data: {tool, arguments, status: "running"|"done"|"error"}
event: file_update ← 工作目录文件变化(新DMP生成)
data: {filename, action: "created"|"modified"}
event: error ← 错误信息
event: done ← 生成完成
data: {output_file: "DMP-xxx.docx", report: "..."}

后端 Chat API

POST /api/chat/send
Content-Type: application/json
{ "message": "用户输入文本" | "选择A" | "填写xxx" }
→ 返回 SSE 流 (text/event-stream)
→ 后端持有 Claude SDK session，处理多轮对话

POST /api/chat/start-dmp
Content-Type: application/json
{}
→ 触发 DMP 生成流程
→ 加载 protocol-to-dmp skill + 工作目录中的日志和方案
→ Claude 按 skill workflow 执行: trace → review → fill template
→ 过程中有问题通过 SSE question 事件推送

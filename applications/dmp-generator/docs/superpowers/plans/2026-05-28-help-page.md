# Help Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/help` static page with step-by-step user guide and FAQ, plus help button entry points in ChatPage and LogFormPage headers.

**Architecture:** New `HelpPage.tsx` component rendered at `/help` route behind ProtectedRoute. Two existing pages (ChatPage, LogFormPage) each get a `?` help button in their header that navigates to `/help`. All content is static Chinese text — no API calls, no state management.

**Tech Stack:** React 18 + TypeScript + Tailwind CSS + react-router-dom v6

# DMP 数据管理计划生成平台 — 项目汇报

## 一、项目概述

本项目是一个面向临床试验数据管理的 **AI 驱动 DMP（数据管理计划）自动生成平台**，支持用户上传试验方案文档、填写项目元数据后，由 AI 自动生成符合中国临床试验规范的中文 DMP Word 文档。

- **项目名称**：DMP Generation Platform
- **技术架构**：FastAPI（后端）+ React 18 + TypeScript（前端）+ Claude Code CLI（AI 引擎）
- **代码规模**：约 5,400 行（后端 695 行 + 前端 1,481 行 + AI 技能脚本 3,212 行）
- **开发周期**：25 个增量提交，从 scaffold 到完整功能交付

## 二、核心功能

### 2.1 用户系统
- JWT（HS256）认证，24 小时有效期
- bcrypt 密码哈希
- 注册 / 登录 / 自动续期

### 2.2 项目与工作空间管理
- 多项目隔离，每个用户独立工作空间目录
- 路径穿越防护（`safe_path`）
- 项目创建 / 切换 / 删除

### 2.3 DM 日志表单
- 23 个字段，含条件显示逻辑（如选择"EDC + 其他"才显示其他系统详情字段）
- 支持多版本追加保存（JSON 数组追加）
- 表单字段联动：EDC/PDC 切换、随机系统、外部数据等依赖链

### 2.4 文件管理
- 拖拽上传试验方案（仅 .docx，最大 50MB）
- 按分类展示：Logs / Protocols / DMP Outputs
- 文件下载 / 删除

### 2.5 DMP 生成引擎（核心）
- **模板选择**：根据 DM 日志自动选模板（随机系统 / 登记系统 / 无随机无登记）
- **证据溯源（Trace）**：从方案和 DM 日志提取非固定内容，逐项记录来源、证据、状态
- **语义审查**：LLM 辅助审查高风险字段（样本量、研究设计、端点分类、分析人群）
- **Few-shot 格式约束**：参照范例格式化输出
- **Protocol/DM-log 交叉检查**：检测方案与日志之间的不一致
- **DM-log 内部一致性检查**：检测父子字段决策冲突
- **顺序确认门**：逐个向用户提问未解决的确认项
- **Word 模板应用**：将确认值填入模板副本，处理封面/签章页/正文/页眉页脚占位符
- **AI 披露**：告知用户哪些字段经过 AI 处理

### 2.6 使用帮助
- 六步图文教程页面（注册 → 登录 → 填表 → 上传 → 生成 → 问答）
- 4 条常见问题 FAQ
- 各页面 Header 快捷帮助入口

## 四、关键设计决策

1. **同步生成器 + Queue 桥接**：DMP 编排器用 `threading.Thread` 将 Claude SDK 流式输出桥接到 SSE，支持任意 `StreamingResponse` 迭代
2. **QUESTION 标记格式**：`[[QUESTION:type:choice]]...[[END_QUESTION]]` 内嵌在 Claude 文本流中，前端解析为交互式卡片
3. **递归条件字段可见性**：表单字段支持多级依赖链，`isVisible` 递归检查父字段可见性
4. **语义审查不可跳过**：prompt 强制要求执行完整的 semantic_review → fewshot_format → 交叉检查 → 顺序确认门流水线
5. **多列表格行处理**：`semantic_blocks` 支持按换行和 ` | ` 两种方式切分，适配方案文档中不同表格结构

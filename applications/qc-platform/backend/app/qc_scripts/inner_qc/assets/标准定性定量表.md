# 标准定性定量表 · QC 核查规则与代码

**对应类型**：`标准定性定量表`（CSV 文件名里的"类型"字段）
本文档两部分：**一、自然语言规则**（要查什么）｜ **二、代码模板**（怎么写脚本）。

---

## 这类表是什么

最常见的基线/疗效统计表。一列列"指标"（年龄、性别、疗效分级），每个分析组（试验组/对照组/合计）一列，格子里是统计量——
- 连续变量：中位数、四分位数(Q1/Q3)、最小值、最大值；
- 分类变量：每个类别的"人数(百分比)"，如 `24(48.0%)`；
- 例数：常写成"例数(缺失数)"，如 `49(1)`。

---

# 一、自然语言规则

## 本表内即可完成的规则

### R-006　例数 + 缺失 = 总人数
- **查什么**：写成"例数(缺失)"的格子，例数加缺失数应等于这一组的总人数 N。
- **判定**：相等→通过；对不上→**先别急着报错**，可能是只在亚组里统计的指标（如"血糖控制情况"只统计糖尿病患者），人数本就少。这种标"待人工复核"。

### R-007　连续变量统计量大小顺序
- **查什么**：最小值 ≤ Q1 ≤ 中位数 ≤ Q3 ≤ 最大值。
- **判定**：顺序正确→通过；任何一个比后面的大→问题（典型是数字写颠倒）。

### R-016　各类别百分比之和 ≈ 100%
- **查什么**：一个分类变量（如疗效分级 CR/PR/SD）下各类别百分比加起来应接近 100%。
- **判定**：允许四舍五入零头（类别越多容差越大）；明显偏离→问题。

### R-017　百分比 = 人数 ÷ 总人数
- **查什么**：每个类别的百分比 = 该类别人数 ÷ 该组总人数 × 100。
- **判定**：差 ≤ 0.15 个百分点→通过；差太多→问题。
- **前提**：先确认各类别人数之和等于总人数，否则跳过（避免子集分母误判）。

### R-025　各类别人数之和 = 总例数
- **查什么**：一个分类变量下各类别人数加起来应等于该组总例数。
- **判定**：相等→通过；对不上→问题。

## 需要"人群划分表"数据作基准的规则

> 用到人群划分表给出的 FAS/ITT/mITT/PPS/SS 各组人数。有基准文件就核对，否则留合并阶段。

### R-003　表题分析集 ↔ 表内合计人数
- 表题标"（FAS）"，表里合计人数**不应超过** FAS 总人数。
- **用"不超过"而非"必须相等"**：子集表（只统计女性、基线化验）人数本就更少，正常；只有比该集还大才是错。

### R-009　表头各组 N ↔ 人群划分表
- 表头每组的 N **不应超过**人群划分表里该组的人数（同样用"不超过"）。

### R-028　表题分析集 ↔ 本表合计人数上限
- 表题声明的分析集（如"（FAS）"），本表合计人数**不能超过** `baseline[FAS]["合计"]`。
- 合计 > 基准 → 报 MAJOR；相等或小于（子集表）都不报。
- 反例：表题（FAS）合计=100 ｜ baseline FAS=89 → 报 MAJOR。
- 反例：表题（FAS）合计=45 ｜ baseline FAS=89（女性亚组子集表）→ **不报**。
- 反例：表题（FAS）合计=89 ｜ baseline FAS=89 → **不报**（相等）。
- 若合计恰等于另一分析集，note 附带提示（可能是标签错位线索）。

### R-036　表头出现的 FAS/ITT/mITT/PPS/SS 要与表题一致
- 表头列里若出现 FAS/ITT/mITT/PPS/SS 字样，必须都包含在表题声明的分析集里，否则报错位。

## 2.2 本表规则核查片段

```python
# level 取 CRITICAL/MAJOR/MINOR/SUGGESTION/待人工；数据算术违例默认 MAJOR，可按判断升降级。

# —— 连续/例数指标（已定位到某指标某组的单元格 cell、该组总人数 N）——

# R-006 例数+缺失=N（对不上→待人工，可能是亚组统计）
n, miss = parse_n_missing(cell)              # "49(1)"
if n is not None and N:
    if check_sum(N, [n, miss]) is False:
        iss.add("R-006", "待人工", f"{var}·{group}", N, n + (miss or 0),
                "例数+缺失≠N，可能只在亚组统计，请人工确认")

# R-007 五数次序 min≤Q1≤中位≤Q3≤max
seq = [mn, q1, med, q3, mx]
if check_ordered(seq) is False:
    iss.add("R-007", "MAJOR", f"{var}·{group}", "min≤Q1≤中位≤Q3≤max",
            "/".join(str(x) for x in seq))

# —— 分类变量：levels = {"CR":(20,40.0),"PR":(15,30.0),"SD":(15,30.0)}，N=50 ——
ns   = [n for n, _ in levels.values()]
pcts = [p for _, p in levels.values()]

# R-025 各类别人数之和=例数
if check_sum(N, ns) is False:
    iss.add("R-025", "MAJOR", f"{cat}·{group}", N, sum(ns))

# R-016 各类别%之和≈100（容差随类别数增大）
if check_sum(100, pcts, tol=pct_tol(len(pcts))) is False:
    iss.add("R-016", "MAJOR", f"{cat}·{group}", "≈100", round(sum(pcts), 1))

# R-017 每个%=n/N（先确认 Σn==N）
if check_sum(N, ns):
    for lv, (n, p) in levels.items():
        if check_pct(p, n, N) is False:
            iss.add("R-017", "MAJOR", f"{cat}/{lv}·{group}", round(n / N * 100, 1), p)
```

## 2.3 需要基准的规则片段（baseline 从人群划分表读入）

```python
# baseline = {"FAS":{"试验组":50,"对照组":48,"合计":98}, "PPS":{...}, "SS":{...}}
# ts=表题声明的分析集；denom=本表合计人数；nbg={组:N}；name=表名；title_set_list=表题集合列表

# R-003 表题分析集 ↔ 表内合计（用 ≤）
if ts in baseline and check_le(denom, baseline[ts]["合计"]) is False:
    iss.add("R-003", "MAJOR", f"表题{ts}", f"≤{baseline[ts]['合计']}", denom)

# R-009 表头各组N ↔ 人群划分表（用 ≤）
for g, n in nbg.items():
    if ts in baseline and g in baseline[ts] and check_le(n, baseline[ts][g]) is False:
        iss.add("R-009", "MAJOR", f"{g}·{ts}", f"≤{baseline[ts][g]}", n)

# R-028 表题分析集 ↔ 本表合计（合计 > baseline 才报，允许子集表）
if ts in baseline and nbg.get("合计") is not None and nbg["合计"] > baseline[ts]["合计"]:
    other = [S for S in baseline if baseline[S]["合计"] == nbg["合计"] and S != ts]
    hint = f"（另与 {'/'.join(other)} 合计相同）" if other else ""
    iss.add("R-028", "MAJOR", f"表题{ts}", f"≤{baseline[ts]['合计']}", f"{nbg['合计']}{hint}")

# R-036 表头出现的 FAS/ITT/mITT/PPS/SS ⊆ 表题集合
bad = {g for g in nbg if g in ("FAS", "ITT", "mITT", "PPS", "SS")} - set(title_set_list)
if bad:
    iss.add("R-036", "MAJOR", "表题↔表头", f"⊆{title_set_list}", "、".join(sorted(bad)))
```

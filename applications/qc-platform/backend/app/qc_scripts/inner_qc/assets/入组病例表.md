# 入组病例表 · QC 核查规则与代码

**对应类型**：`入组病例表`（xlsx 文件名里的"类型"字段）
本文档两部分：**一、自然语言规则** ｜ **二、代码模板**。

---

## 这类表是什么

入组病例分布表。表题含「入组病例」关键词。表头是各组（试验组/对照组/合计），分母 N 取自**随机化人群**（入组人群）；行项目一般是"随机入组、FAS、PPS、SS、剔除原因…"。
- 表内只有**随机入组**这一行（或列）的格子写的是"n(百分比)"，其百分比应等于 n ÷ 随机化人群该组 N × 100。
- 其余行（FAS/PPS/SS、各剔除原因等）的分母可能是随机入组而非随机化人群，**百分比口径不一**，故 R-017 仅适用于"随机入组"行/列。

---

# 一、自然语言规则

## 本表内即可完成的规则

### R-017　百分比 = 人数 ÷ 总人数（仅"随机入组"行/列）
- **查什么**：仅"随机入组"行/列的每个"n(%)"，其百分比应等于该格人数 ÷ 该组随机化人群 N × 100。
- **判定**：差 ≤ 0.15 个百分点→通过；差太多→问题；N 取不到或非随机入组行→跳过。
- **范围限定**：仅核查表中标注为"随机入组"的行（或列）。其他行（FAS/PPS/SS、剔除原因等）口径不同，**静默跳过**，不要按本规则报错。

## 需要"人群划分表"数据作基准的规则

### R-009　表头各组 N ↔ 人群划分表（随机化人群）
- **查什么**：表头每组的 N 不应超过人群划分表里该组的**随机化人群（入组总人数）**。
- **判定**：满足"≤"→通过；超过→问题。基准取不到→跳过。

## 需要"外部参照"的规则（`external_ref.json` 存在时执行）

### R-052　"随机入组"行合计 = 随机表总人数
- **查什么**：本表"随机入组"行的**合计**人数，应等于 `external_ref.randomization.total_successful`（即筛选成功的总数）。
- **判定**：相等→通过；不等→MAJOR。外部无随机化信息→跳过。
- **提示**：若表里只有"随机入组"分组人数（试验/对照）而无合计列，可先求和再比对。

### R-050　各中心的试验组/对照组/合计病例数一致（若本表分中心列举）
- 若本表把各中心的入组数分行/分块列出，应等于 `external_ref.by_center[中心号]`。
- 无分中心维度→跳过。

# 二、代码模板

> subagent 读入 xlsx 后：先用 `find_N` 扫表头定位组列与每组的随机化人群 N，再定位"随机入组"行/列，仅对该行的"n(%)"格子跑 R-017。所有工具函数从共享库 `qc_lib` import。

## 2.1 通用工具 + 骨架（复制即用）

```python
import sys, os, json
sys.path.insert(0, "scripts")   # ← 换成本 skill 的 scripts 目录（绝对路径更稳）
from qc_lib import read_grid, parse_n_pct, find_N, check_pct, check_le, check_equal, lead_int, Issues

# 由 dispatch 提示给出：XLSX_PATH、IDX(编号)、TITLE(表题)、ts(表题分析集="随机化人群")、nbg({组:随机化人群N})
grid = read_grid(XLSX_PATH)                     # 读 xlsx，二维 str
iss  = Issues(table_index=IDX, table_type="入组病例表", title=TITLE,
              analysis_set=ts, n_by_group=nbg)

# 加载 external_ref（可选；文件不存在则 R-050/R-052 静默跳过）
ext_ref = {}
_ref_path = "tables_output/external_ref.json"
if os.path.exists(_ref_path):
    with open(_ref_path, encoding="utf-8") as f:
        ext_ref = json.load(f)

# 核查完毕后落盘：iss.to_json(f"qc_output/qc_{IDX}.json")
```

## 2.2 本表规则核查片段

```python
# level 取 CRITICAL/MAJOR/MINOR/SUGGESTION/待人工；数据算术违例默认 MAJOR。

# R-017 百分比=n/N，仅限「随机入组」行/列
# 已定位到行标签 row_label、组 group、单元格 cell、该组随机化人群总人数 N
if row_label == "随机入组":
    n, p = parse_n_pct(cell)                  # "50(100.0%)"
    if n is not None and p is not None and N:
        if check_pct(p, n, N) is False:
            iss.add("R-017", "MAJOR", f"随机入组·{group}", round(n / N * 100, 1), p)
# 其他行（FAS/PPS/SS、剔除原因等）的百分比口径不同，静默跳过
```

## 2.3 需要基准的规则片段（baseline 从人群划分表读入）

```python
# baseline = {"FAS":{...}, "PPS":{...}, "SS":{...}, "随机化人群":{"试验组":50,"对照组":48,"合计":98}}
# ts="随机化人群"；nbg={组:表头N}；本表分析集固定为"随机化人群"

# R-009 表头各组 N ↔ 人群划分表（随机化人群，用 ≤）
if "随机化人群" in baseline:
    for g, n in nbg.items():
        if g in baseline["随机化人群"] and check_le(n, baseline["随机化人群"][g]) is False:
            iss.add("R-009", "MAJOR", f"{g}·随机化人群", f"≤{baseline['随机化人群'][g]}", n)
```

## 2.4 用 external_ref 的规则片段（**Phase 3 专用**）

> **执行阶段**：Phase 3 外部核查阶段执行；Phase 5 subagent 请**跳过本节**（Phase 3 已产出对应报告 `qc_ext_<编号>.json/md`）。
> Phase 3 subagent 只跑本节的 R-050 / R-052；不跑 §2.2 的 R-017、§2.3 的 R-009。

```python
# R-052 "随机入组"行合计 = 随机表 total_successful
rand_info = ext_ref.get("randomization") or {}
expected_success = rand_info.get("total_successful")
if expected_success is not None and random_total_cell is not None:
    # random_total_cell: 已定位到"随机入组"行的合计单元格；若无合计单元格
    # 可用 sum([随机入组·试验组, 随机入组·对照组]) 求和
    actual = lead_int(random_total_cell)
    if actual is not None and check_equal([actual, expected_success]) is False:
        iss.add("R-052", "MAJOR", "随机入组·合计", expected_success, actual)

# R-050 分中心一致（若本表分中心：center_rows=[(cid, {"试验组":cell,"对照组":cell,"合计":cell}),...]）
# by_center 结构：{"01": {"随机化人群":{...}, "FAS":{...}, "PPS":{...}, ...}, "合计":{...}}
# 入组病例表分析集通常是"随机化人群"——直接查 by_center[cid]["随机化人群"]
# （不过滤纳入/剔除，中心内每个筛选号一人）；若表能明确落到某具体分析集，
# 也查对应槽位（FAS/PPS/SS/ITT/mITT，只算被标"纳入"）。分析集为 "-" 才跳过。
_ACCEPT = ("随机化人群", "FAS", "PPS", "SS", "ITT", "mITT")
by_center = ext_ref.get("by_center") or {}
analysis_set = "<从 ##META_ANALYSIS_SET 取，如 '随机化人群'>"  # subagent 应从元数据填入
if by_center and center_rows and analysis_set in _ACCEPT:
    for cid, cells in center_rows:
        center_data = by_center.get(str(cid)) or by_center.get(str(cid).lstrip("0") or "0")
        if not center_data:
            continue
        ref_row = center_data.get(analysis_set)
        if not ref_row:
            continue
        for grp in ("试验组", "对照组", "合计"):
            actual = lead_int(cells.get(grp))
            expected = ref_row.get(grp)
            if actual is None or expected is None:
                continue
            if check_equal([actual, expected]) is False:
                iss.add("R-050", "MAJOR", f"中心{cid}·{analysis_set}·{grp}", expected, actual)
```

# F_G1_QUANSUB_N_N 模板

定量指标亚组描述表（单组-无缺失）

## 模板说明

适用于单组试验中，对定量指标（如实验室检查值、生命体征等）按亚组（如年龄组、性别等）进行描述性统计分析。

## 文件结构

```
F_G1_QUANSUB_N_N/
├── F_G1_QUANSUB_N_N.json  # 语义JSON模板定义
├── fill_template.py       # 数据填充脚本
├── gen_docx.py            # Word文档生成脚本
├── 填充数据.json          # 示例数据文件
└── README.md              # 本说明文件
```

## 使用方法

### 1. 准备数据文件

创建或修改 `填充数据.json` 文件，格式如下：

```json
{
  "table_name": "实验室检查-血常规",
  "subgroups": ["年龄<65岁", "年龄≥65岁"],
  "projects": [
    {
      "name": "白细胞",
      "unit": "10^9/L"
    },
    {
      "name": "红细胞",
      "unit": "10^12/L"
    }
  ]
}
```

**字段说明：**
- `table_name`: 表格名称（可选）
- `subgroups`: 亚组列表，如年龄组、性别等
- `projects`: 指标列表
  - `name`: 指标名称
  - `unit`: 单位（可选）

### 2. 运行数据填充

```bash
python3 fill_template.py
```

执行后会生成 `填充结果.json` 文件，包含填充后的数据结构。

### 3. 生成Word文档

```bash
python3 gen_docx.py 填充结果.json -o 输出文档.docx
```

**参数说明：**
- 第一个参数：填充好的JSON文件路径
- `-o` 或 `--output`：输出Word文件路径（可选，默认为输入文件名.docx）

## 输出格式

生成的Word文档包含：
- 4列表格：亚组 | 项目 | 指标 | 结果 (N=n1)
- 每个指标占5行：例数(缺失)、均值(标准差)、中位数、分位数、最小值/最大值
- 三线表格式（顶线、表头底线、表格底线）
- 字体：英文 Times New Roman，中文宋体，10.5pt

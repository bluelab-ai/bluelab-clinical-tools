## 实现要求

每个未实现模版需要补充以下两个文件：

1. **`fill_template.py`** — 接收语义 JSON + 项目数据，输出填充后的 JSON
2. **`gen_docx.py`** — 接收填充后的 JSON，生成带三线表格式的 Word 文档

可参考同系列已实现模版的代码结构，例如：
- D 系列参考 `D_G1_EN/`、`D_G2_EN/`、`D_G3_EN/`
- F_G2 系列参考 `F_G2_ANCOVA_01/`、`F_G2_RR/` 等
- F_G3 系列参考 `F_G3_CROSS/`、`F_G3_RD/` 等
